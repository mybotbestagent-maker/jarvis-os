# founder/ — входные данные и выводы Founder

Скиллы Founder читают выводы друг друга из этой папки. Сюда кладём ТОЛЬКО реальные данные (CRM, прайс, факты продукта).
Выдуманные цифры = вердикт врёт. ИИ-покупатели добрее живых: прогон — фильтр идей, не доказательство спроса.

## Входные файлы (заполняет Фаррух / берём из CRM)
- inputs/gold-hands.md — услуги, цены, 8 городов, что не делаем, цифры CRM, реальные возражения клиентов
- inputs/neurlead.md — тарифы, факты продукта (кто реально платит)

## Правила
- Порядок: board → competitors → consumer → pricing → offer → cfo → marketing → brand → ops → launch → plan
- Быстрый скрининг любой идеи: /founder-board, затем /founder-consumer --quick. Не прошла — стоп.
- Любое решение дороже ~$500 сначала проходит прогон.
- После «Profitable» — дешёвый реальный тест из founder-launch (10 живых разговоров) до любого бюджета.
- Вердикт plan — вход в разговор с Фаррухом, решение за ним.
- По каждому прогону — одна страница по-русски: вердикт, топ возражений, цифры CFO, что дальше (runs/<дата>-<сценарий>.md).

## Сценарии
- А. Оффер NeurLead (приоритет №1): board → competitors → consumer (панель = владельцы home-service компаний, 1–10 техников) → pricing → offer
- Б. Мембершип Gold Hands: consumer (панель = домовладельцы Miami/Broward из сегментов CRM) → pricing → offer. Home Care $199 vs Home Plus $359
- В. Новый город/услуга: вся цепочка до plan. Not yet или отрицательная юнит-экономика = стоп
- Г. White label NeurLead: board → consumer (панель = агентства/сети) → cfo
